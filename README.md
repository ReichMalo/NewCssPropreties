Nouveautés CSS
Présentation

Ce projet étudiant présente 10 fonctionnalités modernes du CSS et du HTML.

L'objectif est de découvrir ces nouveautés de manière simple, avec pour chacune une explication, un exemple de code et une petite démonstration interactive.

Les 10 fonctionnalités
View Transitions : créer des transitions fluides entre différentes vues.
:has() : sélectionner un élément selon le contenu qu'il contient.
@container : adapter un composant à la taille de son conteneur.
color-mix() : mélanger des couleurs directement en CSS.
text-wrap: balance : améliorer la mise en forme des titres.
@scope : limiter la portée de certaines règles CSS.
light-dark() : gérer facilement les thèmes clair et sombre.
@property : créer des variables CSS typées et animables.
@starting-style : animer l'apparition d'un élément.
popover : créer des fenêtres superposées sans JavaScript.

Chaque fonctionnalité possède également un tableau de compatibilité et une solution de repli lorsque cela est nécessaire.

Objectif

Le but de ce projet est de mieux comprendre les possibilités offertes par les fonctionnalités modernes du web et de voir concrètement comment elles peuvent être utilisées dans un site.
